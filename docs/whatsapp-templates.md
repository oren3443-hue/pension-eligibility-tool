# תבניות WhatsApp לאישור (Glassix / Meta)

תיעוד כל תבניות ה-WhatsApp שהאפליקציה שולחת. **כל אחת חייבת אישור** ב-Glassix → WhatsApp Templates לפני שליחה לעובדים אמיתיים.

> **עדכון 2026-05-12 (שלב ב):** האפליקציה משתמשת עכשיו בתבנית **`pension_agent_intro_v1`**
> — נוסח מצומצם של תבנית "ב" הישנה, ללא הפסקה של "אם בחרת קופה באופן
> עצמאי..." וללא תאריך יעד. ראה סעיף 0 למטה. התבניות `pension_agent_contact_v2`,
> `pension_start_contribution_v2`, ו-`pension_existing_fund_v2` אינן בשימוש יותר
> ב-UI (התיעוד שלהן נשמר היסטורית בסעיפים 1–3).

**Body:**

```
כדי לסייע לך לבחור את המסלול המתאים ביותר עבורך, סוכן הפנסיה שלנו ייצור איתך קשר בקרוב 📞

חשוב לנו לציין כי עומדת לרשותך הזכות לבחור בכל סוכן פנסיוני, קרן או קופה אחרת לפי העדפתך.

```

**Sample values:** `{{1}}` = `אורנה`, `{{2}}` = `יוני 2026`

**מיפוי לקוד:** `{{1}}` ⇄ `{{first_name}}`, `{{2}}` ⇄ `{{eligibility_month}}`

**הבדל מ-`pension_agent_contact_v2`:** הוסרה הפסקה
"אם בחרת קופה באופן עצמאי, רק נבקש שתשלח לנו את הפרטים עד ה-{{3}} לכתובת המייל: payroll@orenmeshi.com."
ולכן אין יותר `{{3}}`. **נדרש אישור חדש ב-Meta** דרך Glassix — בלי זה
ההודעה תיפול או תיחשב session-message.

### מה לעשות
1. Glassix UI → `Settings → WhatsApp Templates → New Template`. שם:
   `pension_agent_intro_v1`. Body: כפי שלמעלה. Sample values: כפי שלמעלה.
   Category: `UTILITY`. שפה: `he`.
2. ממתינים לאישור Meta (24–48 שעות).
3. **n8n: אין מה לעדכן**. ה-API של Glassix (`POST /protocols/send`) מקבל
   את ה-body המרונדר כ-`text`/`message` ומתאים אותו לתבנית מאושרת
   אוטומטית — אין שדה `template_name`/`templateId` בקריאה. ה-workflow
   `Send Glassix WA` ממשיך לעבוד כפי שהוא ויתחיל להשתמש בתבנית החדשה
   ברגע שתאושר ב-Meta.

⚠️ **חלון מעבר:** עד שה-Meta יאשר, שליחת WhatsApp לעובדים חדשים תיכשל
(`session-message` רק תוך 24 שעות מהודעה אחרונה של העובד). מומלץ לחכות
לאישור לפני שליחה מסיבית.

---

> **חשוב:** WhatsApp Business דורש placeholders ממוספרים (`{{1}}`, `{{2}}`...). באפליקציה אנחנו משתמשים בשמות (`{{first_name}}`, `{{eligibility_month}}` וכו'). הקוד מרנדר את הטקסט המלא לפני השליחה, ו-Glassix משווה לתבנית המאושרת לפי תוכן ה-body. **התאמה חייבת להיות בייט-לבייט** — כל שינוי קוסמטי בקוד חייב לעבור אישור מחדש ב-Meta.
>
> **הערה על המייל:** כל התבניות כוללות את המייל כטקסט פשוט `payroll@orenmeshi.com`. WhatsApp מזהה אותו אוטומטית כקליקבילי. אם Glassix דורש פורמט אחר (למשל Markdown או HTML link), צריך לעדכן את הקבוע `PAYROLL_EMAIL` ב-`src/lib/n8n.ts` בהתאם.

## איך לאשר ב-Glassix

`Settings → WhatsApp Templates → New Template` → מזין את ה-fields למטה. Meta מאשרת בד"כ תוך 24-48 שעות. אם נדחה — Glassix יראה את הסיבה.

## אזהרות

### Emoji
- 👋 (Template 2) ו-🩵 (כל השלושה) — Meta בד"כ מאשרת. אם נדחה: להחליף ל-טקסט פשוט.

### שינויים בעתיד
כל שינוי בנוסח (גם רווח, פסיק, אימוג'י) דורש **אישור מחדש**. תהליך מומלץ:
1. לערוך את ה-template ב-`src/App.tsx` (`TEMPLATE_PRESET_*`)
2. לעדכן את ה-body כאן בתיעוד
3. ליצור גרסה חדשה ב-Glassix (`pension_start_contribution_v2` וכו')
4. רק אחרי ש-Meta אישרה — לדחוף לאתר

### המייל
`payroll@orenmeshi.com` קשיח ב-3 התבניות (משתנה `{{payroll_email}}` בקוד). אם המייל משתנה — לעדכן את `PAYROLL_EMAIL` ב-`src/lib/n8n.ts` ולאשר 3 תבניות מחדש.
