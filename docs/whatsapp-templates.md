# תבניות WhatsApp לאישור (Glassix / Meta)

תיעוד כל תבניות ה-WhatsApp שהאפליקציה שולחת. **כל אחת חייבת אישור** ב-Glassix → WhatsApp Templates לפני שליחה לעובדים אמיתיים.

> **חשוב:** WhatsApp Business דורש placeholders ממוספרים (`{{1}}`, `{{2}}`...). באפליקציה אנחנו משתמשים בשמות (`{{first_name}}`, `{{eligibility_month}}` וכו'). הקוד מרנדר את הטקסט המלא לפני השליחה, ו-Glassix משווה לתבנית המאושרת לפי תוכן ה-body. **התאמה חייבת להיות בייט-לבייט** — כל שינוי קוסמטי בקוד חייב לעבור אישור מחדש ב-Meta.
>
> **הערה על המייל:** כל התבניות כוללות את המייל כטקסט פשוט `payroll@orenmeshi.com`. WhatsApp מזהה אותו אוטומטית כקליקבילי. אם Glassix דורש פורמט אחר (למשל Markdown או HTML link), צריך לעדכן את הקבוע `PAYROLL_EMAIL` ב-`src/lib/n8n.ts` בהתאם.

## איך לאשר ב-Glassix

`Settings → WhatsApp Templates → New Template` → מזין את ה-fields למטה. Meta מאשרת בד"כ תוך 24-48 שעות. אם נדחה — Glassix יראה את הסיבה.

## 1. `pension_agent_contact` — סוכן ייצור קשר (הודעה ב) ✅ מאושר

| שדה | ערך |
|---|---|
| Template Name | `pension_agent_contact` |
| Category | `UTILITY` |
| Language | Hebrew (`he`) |

**Body:**

```
שלום {{1}},

ברכות! החל מחודש העבודה {{2}} תחל ההפרשה הפנסיונית שלך.

סוכן הפנסיה של החברה יצור איתך קשר בהקדם כדי לסייע לך בבחירת הקופה והמסלול המיטביים עבורך. עומדת לרשותך הזכות לבחור בכל סוכן או קופה אחרת לפי שיקול דעתך.

במידה ובחרת בקופה באופן עצמאי, עליך להעביר לנו את הפרטים עד ל-{{3}} לכתובת המייל: payroll@orenmeshi.com.

בהצלחה,
מחלקת שכר, אורן משי 🩵
```

**Sample values:** `{{1}}` = `אורנה`, `{{2}}` = `יוני 2026`, `{{3}}` = `15 ביוני 2026`

**מיפוי לקוד:** `{{1}}`⇄`{{first_name}}`, `{{2}}`⇄`{{eligibility_month}}`, `{{3}}`⇄`{{deadline_date}}`

## 3. `pension_existing_fund` — יש קופה (הודעה ג) ⏳ דרוש אישור

| שדה | ערך |
|---|---|
| Template Name | `pension_existing_fund` |
| Category | `MARKETING` (Meta סיווג מחדש) |
| Language | Hebrew (`he`) |

> **השלכות של קטגוריה MARKETING:**
> - דורש opt-in מהעובד לפני שליחת הודעות שיווק (Meta מחמירה בזה)
> - עלות גבוהה יותר ל-conversation (תלוי במחירון WhatsApp Business)
> - עלול להיכלל במגבלות frequency cap של Meta (24h cooldown בין הודעות שיווק)
> - לא חוסם שליחה — רק מצריך מודעות אופרטיבית

**Body (להזין כשמגיש לאישור):**

```
שלום {{1}},

עדכון קצר ממחלקת השכר: הפרשות הפנסיה שלך פעילות בקופה {{2}}.

אם ברצונך לשנות פרטי קופה, להוסיף מסמכים או לעדכן פרטים — אנא שלח/י אותם למייל: payroll@orenmeshi.com.

תודה,
מחלקת שכר, אורן משי 🩵
```

**Sample values:** `{{1}}` = `אורנה`, `{{2}}` = `מבטחים החדשה`

**מיפוי לקוד:** `{{1}}`⇄`{{first_name}}`, `{{2}}`⇄`{{primary_fund}}`

## אזהרות

### Emoji
- 👋 (Template 2) ו-🩵 (כל השלושה) — Meta בד"כ מאשרת. אם נדחה: להחליף ל-טקסט פשוט.

### שינויים בעתיד
כל שינוי בנוסח (גם רווח, פסיק, אימוג'י) דורש **אישור מחדש**. תהליך מומלץ:
1. לערוך את ה-template ב-`src/App.tsx` (`TEMPLATE_PRESET_*`)
2. לעדכן את ה-body כאן בתיעוד
3. ליצור גרסה חדשה ב-Glassix (`pension_start_contribution_v2` וכו')
4. רק אחרי ש-Meta אישרה — לדחוף לאתר

### המייל
`payroll@orenmeshi.com` קשיח ב-3 התבניות (משתנה `{{payroll_email}}` בקוד). אם המייל משתנה — לעדכן את `PAYROLL_EMAIL` ב-`src/lib/n8n.ts` ולאשר 3 תבניות מחדש.
